# Rainbow Paint Globe

A small Rust and OpenGL demo that renders an animated, marbled 3D globe with saturated rainbow colors.

## Run

Install Rust with `rustup`, then run:

```powershell
cargo run
```

Press **Esc** or close the window to exit.

## Technologies

- Rust
- GLFW for the window and OpenGL context
- OpenGL 3.3 shaders for the ray-marched 3D globe
